# Introduction Physical AI & Humanoid Robotics

Welcome to Module 1 of the Physical AI & Humanoid Robotics book! This module will introduce you to the Robot Operating System 2 (ROS 2), which serves as the "nervous system" for humanoid robots.

## Overview

In this module, you will learn:
- The fundamental concepts of ROS 2: Nodes, Topics, and Services
- How to bridge Python agents to ROS controllers using rclpy
- How to model humanoid robots using URDF (Unified Robot Description Format)

These concepts form the foundation for developing sophisticated humanoid robotics applications.

## Target Audience

This module is designed for:
- Students learning humanoid robotics
- Developers working with ROS 2 middleware
- Anyone interested in understanding robot control systems

## Prerequisites

Before starting this module, you should have:
- Basic programming knowledge in Python
- Understanding of Linux command line
- Familiarity with robotics concepts (helpful but not required)

## Structure

This module is organized according to the book's structure: Concepts → Theory → Setup → Implementation → Code → Exercises.
