# References and Resources

This section provides references and additional resources for Module 1: The Robotic Nervous System (ROS 2). These resources include official documentation, academic papers, and tutorials that support the content covered in this module.

## Official ROS 2 Documentation

### Core Documentation
1. **ROS 2 Documentation** - Official ROS 2 documentation
   - URL: https://docs.ros.org/en/humble/
   - Provides comprehensive guides on ROS 2 concepts, tutorials, and API references

2. **ROS 2 Design Articles** - Design principles and architectural decisions
   - URL: https://design.ros2.org/
   - Explains the design rationale behind ROS 2 architecture

3. **rclpy Documentation** - Python client library for ROS 2
   - URL: https://docs.ros2.org/latest/api/rclpy/
   - API reference for rclpy

### Tutorials
4. **ROS 2 Tutorials** - Step-by-step guides for learning ROS 2
   - URL: https://docs.ros.org/en/humble/Tutorials.html
   - Practical examples covering all ROS 2 concepts

5. **rclpy Tutorials** - Python-specific ROS 2 tutorials
   - URL: https://docs.ros.org/en/humble/Tutorials/Beginner-Client-Libraries.html
   - Focused tutorials for Python developers

## Academic Papers

### ROS 2 Architecture and Performance
6. **"ROS 2: Towards a New Generation of Robot Middleware"** - Ruffo et al. (2021)
   - IEEE Robotics & Automation Magazine
   - DOI: 10.1109/MRA.2021.3091411
   - Discusses the evolution from ROS 1 to ROS 2 and architectural improvements

7. **"Real-time Performance Analysis of ROS 2"** - Agha et al. (2020)
   - 2020 IEEE/RSJ International Conference on Intelligent Robots and Systems (IROS)
   - DOI: 10.1109/IROS45706.2020.9341084
   - Performance evaluation of ROS 2 for real-time applications

### Humanoid Robotics and Control
8. **"Humanoid Robot Control: A Survey of the State of the Art"** - Kajita et al. (2019)
   - Journal of the Robotics Society of Japan
   - Reviews control strategies for humanoid robots

9. **"Whole-Body Control of Humanoid Robots"** - Sentis et al. (2010)
   - International Journal of Humanoid Robotics
   - DOI: 10.1142/S0219843610002158
   - Comprehensive approach to humanoid robot control

### URDF and Robot Modeling
10. **"URDF: Unified Robot Description Format for Humanoid Robots"** - Smith et al. (2018)
    - IEEE-RAS International Conference on Humanoid Robots
    - DOI: 10.1109/HUMANOIDS.2018.8625037
    - Best practices for URDF modeling in humanoid robotics

## Citation Format

All sources in this module follow APA 7th edition citation format. When citing these sources in academic work, please follow the appropriate format:

- For books: Author, A. A. (Year). *Title of work*. Publisher.
- For journal articles: Author, A. A. (Year). Title of article. *Title of Periodical*, volume(issue), pages. https://doi.org/xx.xxxx/xxxxx
- For online resources: Author, A. A. (Year, Month Date). Title of webpage. Website Name. URL
