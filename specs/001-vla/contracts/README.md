# API Contracts

This directory contains API contracts for the Vision-Language-Action (VLA) system. These contracts define the interfaces between different components of the VLA system, including voice processing, cognitive planning, and simulation integration.

## Available Contracts

- VLA API: Defines endpoints for voice command processing, action planning, and execution feedback
- Perception Interface: Defines data formats for vision-language integration
- Simulation API: Defines interfaces for Gazebo and Unity simulation environments

For detailed API specifications, see the individual contract files in this directory.
